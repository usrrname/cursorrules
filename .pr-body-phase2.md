## Summary
Phase 2 of Claude Code support - CLI enhancements for IDE selection

## Changes
- ✅ Added `--ide` flag for choosing cursor|claude|both
- ✅ Added interactive IDE selection prompt when `--ide` not specified
- ✅ Added `--dry-run` flag to preview downloads without writing files
- ✅ Added `--validate` flag for post-download file validation
- ✅ Created `cli/utils/ide-selection.mjs` utility for IDE choice handling
- ✅ Updated `download-files.mjs` to support IDE-specific downloads
- ✅ Updated `commands.mjs` with IDE-aware interactive mode
- ✅ Updated CLI help text with examples for all new flags
- ✅ Support for downloading both Cursor and Claude configurations

## New CLI Options

```bash
# Target specific IDE
npx @usrrname/cursorrules --ide cursor --flat
npx @usrrname/cursorrules --ide claude --dry-run
npx @usrrname/cursorrules --ide both --output ./config

# Preview without downloading
npx @usrrname/cursorrules --ide claude --dry-run

# Validate after download
npx @usrrname/cursorrules --ide both --validate

# Interactive mode with IDE selection
npx @usrrname/cursorrules --interactive
```

## Breaking Changes

**None** - All changes are backward compatible:
- Default behavior unchanged (downloads Cursor rules if no `--ide` specified)
- Existing flags continue to work as before
- New flags are opt-in only

## Implementation Details

### IDE Selection Flow
1. If `--ide` flag provided → use specified value
2. If `--interactive` mode → prompt user for IDE selection
3. Otherwise → default to 'cursor' (backward compatible)

### Download Paths by IDE
- **cursor**: `.cursor/rules/`, `.cursor/skills/` (existing behavior)
- **claude**: `.claude/rules/`, `.claude/commands/`, `.claude/skills/`, `.claude/hooks/`
- **both**: All of the above
